Support

support@rh1.tech

Questions about the software go to support@rh1.tech. Bugs and feature requests are better on GitHub, where they stay public and get fixed in the open.

Anything about a particular account — a password reset, a suspended login, data held on the server — belongs to whoever runs the server you sign in to. We have no access to it.

Your recovery code

Pheme shows it once, when your first device sets up encryption. Write it down. It is the only thing that opens your history if you lose every device you are signed in on — nobody can reproduce it, reset it, or recover it for you, and that is the point: a code we could recover would be a code we could use.

You can see it again on a device that still has it, and regenerate it, in Settings → Devices & security.

"Back up now" is greyed out

That means this device holds no recovery code — the code was created somewhere else, or local storage was cleared — so it has nothing to seal a backup with. Enter your code in Devices & security and it will start backing up again, including everything read on it since.

Lost or replaced a device

  1. Sign in on the new device.
  2. If another device is still signed in, it hands over your history automatically — keep it online and unlocked until the new one has caught up.
  3. Otherwise enter your recovery code when asked, and the history is restored from the sealed backup.
  4. Remove the lost device in Settings → Devices & security. It immediately stops being able to read anything new.

A message says "Not available on this device"

That message was sent before this device joined the conversation, and it is permanent rather than a loading state — MLS gives a new device no access to what came before it. Restoring from a recovery code, or a handover from a device that already has the history, is what fills it in.

Running your own server

The stack is a Docker Compose file: API, web client, database, push and TURN. See the repository for the deployment guide. You do not need an account with us to run one, and nothing about your instance depends on this site staying up.

Deleting your account

Settings → Account → Delete account. If you cannot reach the app, ask the operator of your server. See the privacy policy for what is removed.
