Note the application ID differs from the iOS bundle ID
(`tech.rh1.pheme.phemeMobile`). That is allowed and nothing depends on them

## Before the first release

1. **Upload key.** `android/app/build.gradle.kts` reads `android/key.properties`
   and falls back to the debug signing config when it is absent, so a checkout
   without the keystore still builds. Release builds must be signed with the
   real upload key, and neither the keystore nor `key.properties` belongs in
   this repository — both are gitignored, keep it that way.
2. **The URLs below.** All placeholders.
3. **Data safety form.** See `data_safety.md`. Play rejects mismatches between
   this form and observed network behaviour, so it is worth reading rather than
   clicking through.

## Content rating

Fill the IARC questionnaire — see `content_rating.md`. Expect **Teen** (ESRB) /
**PEGI 12** or similar, because the app carries user-generated content and
unmoderated person-to-person communication.

## App access

Play asks whether any part of the app is restricted. Answer **All or some
functionality is restricted**, and give:

- Instructions: sign in with the demo credentials; the server address is
  pre-filled on the sign-in screen.
- Username / password: a demo account on a reachable server. Do not put these in
  this repository — enter them in Play Console.

The demo account should have real content in it (a direct chat, a group, a
channel with posts), or the reviewer sees an empty app.

## Ads

**No ads.** There is no advertising SDK in the build.

## Target audience

Not designed for children. Target age 13+ (or 16+ in the EU), which keeps the
app out of the Families programme and away from its extra requirements. A
messenger with unrestricted user-generated content should not be declaring a
child audience.
